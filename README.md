# Universal Reader

A free ebook and document reader: read EPUB, PDF, MOBI, DjVu, CBZ and more on Android, Kindle, Kobo, PocketBook and desktop, with full layout control and annotation tools.

Universal Reader is a fork of the KOReader codebase, maintained as a private build.

## Sync

`.github/workflows/sync.yml` pulls upstream changes from the KOReader project daily, re-applies the Universal Reader branding via `scripts/migrate.py`, and pushes.
